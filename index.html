평탄 지면 RT는 직접파와 지면 정반사를 계산하고, Sionna 직접파는 반사 없이 직접 경로만 계산합니다.

Friis 수식 모드

Sionna를 사용하지 않고 송수신점 사이의 3차원 직선거리와 955MHz 주파수, 측정 H/V 안테나 방향이득으로 자유공간 RSRP를 계산합니다.

파장λ = c / f
3차원 거리d = √(E² + N² + (hrx − htx)²)
자유공간 손실FSPL[dB] = 20 log₁₀(4πd / λ)
송신 방향이득Gt = Gpeak + GV,rel(θ) + GH,rel(φ)
RSRPRSRP[dBm] = (PRE + OffsetRS) + Gt + Gr − FSPL − Lsys

현재 설정은 955MHz, 10MHz, 50RB/600 부반송파, 전체 송신출력 21dBm, Base RE 18.22dBm, RS Power Offset 0dB입니다. RSRP 계산 기준전력은 18.22dBm, 수신 안테나는 Gr=0dBi, 케이블 손실을 포함한 시스템 손실은 Lsys=1dB입니다.

입력값 확인: 21dBm을 600개 RE에 균등 분배하면 RE당 약 −6.78dBm입니다. 현재 Base RE 18.22dBm은 총 46dBm에 해당하므로, 장비값 확인 전까지 두 값은 독립 입력값으로 적용합니다.

세 환경 결과는 모두 같은 절대 RSRP(dBm) 색상 범례를 사용하므로 수신전력 차이를 직접 비교할 수 있습니다.

2D/3D 패턴 분석 보기는 커버리지 계산과 분리된 안테나 상대이득 전용 화면입니다. 옴니·야기·합성 패턴의 H-Plane/V-Plane을 극좌표로 보고, 지면에서 자르지 않은 전체 3D 형상을 회전해 확인합니다.

Data/pattern/260827_pattern.xlsx의 옴니, 야기안테나, 야기+옴니 시트를 로컬 패턴 카탈로그로 변환해 사용합니다. 원본과 카탈로그는 Git에 업로드하지 않습니다.

상대이득 0dB가 가장 강한 방향이며, 음수 값이 작아질수록 그 방향의 방사가 약합니다. 이 값은 RSRP가 아닙니다.

dB 가시화는 작은 부엽도 보이게 반경을 극좌표처럼 표시합니다. 진폭/전력 비례는 물리적인 상대 크기에 가깝지만 약한 로브가 매우 작게 보일 수 있습니다.

약한 부분 표시는 측정값을 변경하지 않고, 약한 로브를 화면에서 어디까지 보일지 정합니다. −20dB는 강한 부분 위주, −60dB는 약한 부분까지 표시합니다.

이상적 옴니 기준(도넛형)은 모든 수평 방위가 같고 위·아래가 약한 이론적 기준입니다. 위에서 보면 원형, 옆에서 보면 도넛 단면으로 보입니다. 이상적 등방성 기준은 3차원 모든 방향이 같은 구형입니다.

수신 고도·거리손실·지면 반사·-100dBm 기준은 사용하지 않습니다. 지도 크기 슬라이더는 실제 도달거리가 아닌 표시 배율입니다.

3D 시점

실제 H-Plane 값을 같은 기준으로 비교한 결과입니다. 위 슬라이더를 움직이면 현재 그림과 수치가 즉시 바뀝니다.

현재 -40dB

청록색 Sionna RT는 계산된 RSRP -100dBm 경계면이고, 주황색 Friis 자유공간은 화면에서 선택한 RSRP 기준과 안테나 패턴으로 다시 계산한 경계면입니다.

Sionna 형상은 별도 3D Radio Map 계산 결과이고, Friis 형상은 Sionna를 사용하지 않고 측정 H/V 안테나 이득과 자유공간 손실식을 역으로 풀어 방향별 임계거리를 계산한 결과입니다.

Friis 기준 RSRP를 −100dBm에서 −80dBm으로 높이면 모든 방향의 경계거리가 1/10로 줄지만 방위별 거리 비율은 동일하므로 측정 패턴의 굴곡은 유지됩니다. 원형 여부는 RSRP 기준이 아니라 안테나 패턴으로 결정됩니다.

이상적 옴니(수평 원형)를 선택하면 위에서 본 Friis 경계면이 원형이 됩니다. 측정 옴니는 실제 H-Plane의 방위별 편차를 그대로 반영합니다.

Sionna 결과 파일의 메타데이터에 기록된 수평 범위·격자·고도 단면·ray 표본 수를 사용하며, 평탄 지면 직접파와 정반사를 포함합니다. 새 패턴으로 결과를 다시 만들면 화면 설명과 상태 표시도 그 계산 범위를 자동으로 따릅니다.

계산된 3차원 RSRP 격자를 선형 전력 공간에서 연속 보간한 뒤 RSRP = -100dBm 교차면을 marching tetrahedra 방식으로 추출했습니다. 표면 안쪽이 -100dBm 이상 수신 가능 영역입니다.

수평과 상단 계산 경계에서는 커버리지가 모두 닫혀 있으므로, 기존 3km 고도면 결과처럼 계산영역 끝에서 잘린 형상이 아닙니다.

기존 Sionna 결과의 각 단말 고도면에서 설정한 기준 이상의 RSRP 셀만 남겨 여러 평면으로 쌓아 보여주는 보조 기능입니다. 기본 기준은 RSRP ≥ -100dBm입니다.

색상점은 실제 Sionna 계산 셀, 밝은 선은 각 고도의 -100dBm 경계, 세로선은 연속된 계산 고도 사이에서 기준을 만족한 위치를 연결한 시각화입니다.

중요: 이 기능은 연속 3D 경계면이 아닙니다. 고도 사이의 세로 연결은 적층 구조를 이해하기 위한 표시이며 추가 Sionna 계산값이 아닙니다. 실제 계산값은 100/200/300/400/500/1000/2000m 고도면에만 존재합니다.

수신 가능 셀이 3km 계산 격자의 바깥 경계까지 닿으면 실제 커버리지 끝이 아니라 시뮬레이션 영역에서 잘린 것입니다. 실제 끝을 보려면 python/sionna_config.py의 GRID_SIZE_M을 늘리고 python/run_coverage.py를 다시 실행해야 합니다.

기존 렌더링 동작을 보존한 분석용 표시입니다.

커버리지 결과 변환을 끄면 260827 이중 야기+옴니의 H-Plane/V-Plane 합성 형상을 표시합니다. 켜면 선택한 커버리지 RSRP를 각도 방향의 3D 형상으로 변환합니다.

커버리지 형상의 크기는 정규화된 상대 RSRP, 색상은 절대 RSRP를 사용합니다. 이 형상은 안테나 고유 방사 패턴이 아니며, 결과 기반 모드에는 틸트·스윙을 중복 적용하지 않습니다.
